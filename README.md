# Xiang Liu Academic Homepage

Clean Jekyll template prepared for `https://lx-ynu.github.io`.

## Edit first

1. `_data/profile.yml` — name, email, Google Scholar, ORCID, avatar and research interests.
2. `_data/publications.yml` — publications and links.
3. `_data/news.yml` — recent updates.
4. `research.md`, `projects.md`, `cv.md` — page content.
5. Put your portrait in `images/` and set `avatar: "/images/your-photo.jpg"` in `_data/profile.yml`.
6. Put your PDF CV at `files/Xiang_Liu_CV.pdf`.

## GitHub Pages

This repository is designed for GitHub Pages with Jekyll. Publish from the `main` branch and `/(root)`.

## Local preview (optional)

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
